# INRAS recorded IF excerpt

Lukas Rienessl and Reinhard Feger, public 77-GHz FMCW radar interference dataset, DOI 10.5281/zenodo.21933926. Source: https://zenodo.org/records/21933926 . Distributed under CC BY 4.0 (https://creativecommons.org/licenses/by/4.0/).

`inras_if_excerpt.mat` is the retained numerical IF subset used by the existing spectral analysis. It retains its native 76–77 GHz configuration and source conditions. It is not a 62-GHz author acquisition, and the underlying source record is not relicensed by the PhantomRadar code license.
